项目里的主要内容

  • 确定性命令中心

    搜索与 g / gh / lg 命令走确定性解析，不必先调用模型。

  • 洛谷题面与公开代码上下文

    组合洛谷题面、手动粘贴的提交与 GitHub 公开文件。

  • 单次确认后调用 OpenRouter

    学习诊断只在明确确认后发送一次请求，未实现多轮诊断。
