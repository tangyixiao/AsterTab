Deterministic · no LLM

先解析命令，再按需调用 AI。

Plain text and g / gh / lg are resolved in pure TypeScript into fixed HTTPS URLs and opened directly. Empty arguments produce a local hint instead of navigating.

ai <request> opens a local diagnostic draft: Luogu statements, pasted submissions and public GitHub file permalinks are assembled and previewed before anything is sent.

当前实现范围 Reading and sending request host permissions on demand, then a single OpenRouter request after explicit confirmation. No multi-turn diagnosis, no private repository access, no background service worker, no plugin marketplace.

  return (
    <main>
      <form onSubmit={event => {
        event.preventDefault();
        const result = parseCommand(input);
        if (result.kind === "search") {
          onNavigate(buildSearchUrl(result));
          return;
        }
        if (result.kind === "agent") {
          setAgentRequest(result.request);
          return;
        }
        if (result.kind === "error") {
          setStatus(result.code === "missing_query" ? "请输入搜索内容。" : "请输入 AI 请求内容。");
          return;
        }
        setStatus("");
      }}>
        <label for="command-input">搜索或输入命令</label>
        <input id="command-input" value={input} onInput={event => { setInput(event.currentTarget.value); setStatus(""); }} autoFocus />
        <button type="submit">搜索</button>
